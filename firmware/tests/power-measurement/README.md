# Power measurement

## 中文

電表到貨後分別量測 idle、ToF 輪詢、RFID 讀取、Wi-Fi 連線與 HTTPS 上傳的平均/峰值電流。以每天事件數做 24 小時加權平均，續航估算使用電池可用容量，不只用標示 1000 mAh。

---

## English

When the power meter arrives, measure average and peak current separately for idle mode, ToF polling, RFID reading, Wi-Fi connection, and HTTPS upload. Build a 24-hour weighted average from the expected daily event count, and estimate runtime from usable battery capacity rather than the nominal 1000 mAh rating alone.
